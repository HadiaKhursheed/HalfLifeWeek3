# Musical Astronaut 
In this project I am making an Astronaut toy musical by giving it musical tunes, face using oled display, wleds for extra party vibes. It is small enough to be kept on my desk. \
For this I designed a Printed Circuit Board that will connect different components of the project togther easily. \
